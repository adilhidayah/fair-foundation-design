Pipe Rack Column Reactions (Base)
Friction forces from piping expansion. Usually applied 100% in longitudinal or 50% transverse.
Clicking this will automatically populate the Load Combinations section below with standard petrochemical combinations (Operating, Empty, Test + Wind/Seismic + Thermal). The wind value is taken as strength-level W, so the ASD combinations apply 0.6W (ASCE 7-22 §2.4.1).
Pipe Rack Guidance
PIP STC01015 / ASCE 7 Notes:

- Tf (Friction): Typically considered acting in only one direction at a time. It does not act simultaneously with Wind/Seismic in extreme combinations unless specified.
- Ta (Anchor): Must be designed for the full calculated thermal force.
- Load Combos: For footing sizing (ASD), the load combinations usually take D + Do + Ta + Tf as the normal operating condition, and D + Do + W/E + (Ta) for environmental conditions.

Load Types
Load typeCodeType
Register which load types apply to this project (Dead, Live, Wind, Seismic, Operating/Thermal, plus any custom type). Code is your own notation (e.g. V, DL, S) — it becomes the column header in the Load Combinations table. Type tells the calculation what the load is: vertical (P), lateral X (Fx/Mz) or lateral Z (Fz/Mx), and whether it is temporary (wind / earthquake → Temporary minimum FS). Enter the actual P/H/M values in "Load Values" — only where you actually have a value to input.
